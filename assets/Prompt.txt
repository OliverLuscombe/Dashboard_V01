PROJECT
Project title:
“Modelling Antarctic Sea Ice with Supervised Machine Learning and Satellite Data”
The project investigates Antarctic sea ice and its relationship with environmental and topographical variables.
The client currently relies heavily on static images/screenshots and separate tables to communicate research findings.
The dashboard should replace that disconnected experience with a dynamic, interactive environment where researchers can explore Antarctic sea ice, environmental conditions and machine learning outputs together.
The system ultimately involves:
Antarctic sea ice data
Environmental data
Topographical / geographic data
Machine learning model outputs
Seasonal comparison
Interactive geographic visualisation
The prototype should communicate the concept of a serious scientific/research tool.
This is NOT:
a consumer weather app
a climate activism website
a marketing landing page
a generic corporate analytics dashboard
a futuristic sci-fi interface
It should feel like a modern scientific research platform.
Think:
NASA Earthdata
Copernicus Climate Data Store
ArcGIS
modern geospatial analytics software
high-quality university research dashboards
BUT make it significantly cleaner, less cluttered and more contemporary.
==================================================
PRIMARY DESIGN GOAL
Design a dashboard that allows a researcher or non-technical stakeholder to very quickly understand:
“What is happening to Antarctic sea ice?”
“Where is it happening?”
“When is it happening?”
“What environmental variables appear to be associated with it?”
“What does the machine learning model identify?”
The dashboard should feel understandable within approximately 5–10 seconds of opening it.
The Antarctic map should be the visual centrepiece.
Avoid overwhelming the user with dozens of graphs immediately.
Use progressive disclosure:
show the most useful information first,
then allow researchers to explore deeper.
